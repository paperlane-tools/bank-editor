# 题库编辑器（bank_editor）

编辑「易智教助手」导出的**题库 JSON** 的图形界面小程序。Python 标准库写的（tkinter），
**不用装任何东西、不用联网**。

当前版本 v2.4。界面上的几条约定：

- **浅色 / 深色**：右上角「🌙 深色」一键切（也可以 `--dark` 启动就进深色）
- **未保存会提醒**：改过之后窗口标题和状态栏右侧亮 ●，这时关窗会先问你要不要存
- **排序看得到**：点表头排序，表头会出现 ▼（降序）/ ▲（升序）；点「#」回到原始顺序
- **缺答案一眼看见**：没有答案的行整行压暗
- **详情面板**：选中一行 → 下方看完整题干、直接改答案；上下之间的横条能拖着调高度

## 怎么开

双击 **`打开题库编辑器.bat`**（也可以把 `.json` 直接拖到它上面打开）。

命令行也行：

```powershell
python quiz\bank_editor\bank_editor.py                 # 空着打开
python quiz\bank_editor\bank_editor.py "C:\...\yzj-bank-2026-10-05.json"
python quiz\bank_editor\bank_editor.py "C:\...\yzj-bank-2026-10-05.json" --dark
```

## 界面能干什么

| 按钮 | 说明 |
|---|---|
| **打开 / 保存 / 另存为** | 保存前自动把原文件备份成 `<名字>.<时间戳>.bak`，改坏能回去 |
| **导出选中…** | 多选（Ctrl / Shift）若干题 → 另存成一个新题库；导完会问你要不要从当前库里删掉 |
| **导出筛选结果…** | 把当前搜索/筛选后**显示出来的这些条**另存成新题库（Ctrl+E），原文件不动 |
| **删除选中** | 二次确认后删（记得点「保存」才写回文件） |
| **撤销** | Ctrl+Z，最多回退 20 步（删除 / 改答案 / 整理 / CSV 写回都能撤） |
| **拆分…** | 6 种拆法，见下；点「预览」先看会拆成几份，**预览不写任何文件** |
| **年级分流…** ★ v2.3 | 按「年级 × 科目」把当前题库分成「25级-语数外」「24级-专业课」这种，可同时输出 `.js` |
| **合并…** | 选多个题库合成一个，同 key 冲突策略可选：用后一个 / 保留已有 / 冲突跳过 |
| **批量归并…** ★ v2.3 | 一次选**一堆**题库文件（或一整个文件夹）→ 合并去重 → 直接按「年级 × 科目」出文件 |
| **整理(去重)** | 「重组」：把指向**同一道题**的多个指纹 key（`q…`+`p…`）合并成一条 |
| **体检** | 条数、题型分布、缺题干、答案为空、同题占多个 key |
| **科目筛选** ★ v2.2 | 下拉里自动列出题库出现过的科目；还能筛「（没标科目）」把老数据挑出来 |
| **来源账号列** ★ v2.2 | 显示 `姓名(学号)`，一眼看出这题是从哪个账号收的 |

表格里 **双击某一行**可以直接跳到答案框改答案；右键有菜单（导出选中 / 删除 / 撤销）。
搜索框支持多个关键词（空格分开，全部命中才算）；旁边能按题型 / 来源筛选。
没选中任何行时，详情面板会显示题库概览（条数、题型分布、同题多 key 的组数）。

快捷键：`Ctrl+O` 打开 · `Ctrl+S` 保存 · `Ctrl+Shift+S` 另存为 · `Ctrl+E` 导出筛选结果 ·
`Ctrl+A` 全选（焦点在输入框里就只全选文字）· `Delete` 删除选中 · `Ctrl+Z` 撤销 ·
`Ctrl+F` 搜索 · `F5` 刷新 · `Esc` 取消选中。

### 拆分方式

| 方式 | 用途 |
|---|---|
| 按题型 | 单选 / 多选 / 判断 / 填空… 各一个文件 |
| 按条数 | 每 N 条一个文件（大库切片） |
| 按题干关键词 | 含关键词的 / 不含的，两个文件 |
| 按来源 | `official`（官方判定）/ `learn`（交卷自学习）/ `import`… |
| **按多组关键词** ★ | 一次分出好几个"班/科目"，写法一行一组：`电气班: 电动机,继电器`；没命中的进「未归类」 |
| **按整卷图片** ★ | `i<hash>@题号` / `d<hash>@题号` 按指纹聚组，同一张卷子的题放一起 |

输出目录默认就填在**题库所在的文件夹**旁边（`拆分-年月日-时分`），不用每次自己找；
拆完会问你要不要直接打开那个目录。

### 按「年级 × 科目」分流 / 批量归并（v2.3）

想做的事：**26 级的语数外归一堆、26 级的专业课归一堆、24 级的语数外归一堆……**

两条路，逻辑一样：

- 单个库 → 工具栏 **「年级分流…」**；
- 好几个账号导出的库（或以前分出来的小文件）→ 工具栏 **「批量归并…」**：
  选文件夹会把里面的 `*.json` 递归收进来，先按 key 合并去重，再分流。

**年级**怎么判：从条目的 `cls`（班级名，如「25级05班」）里抽 `25级`；`cls` 没有就往 `subj`、
题干里找；都找不到就是 `年级未知`。**科目**怎么判：

1. 有 `subj`（课程名）→ 命中「公共课关键词」就是**语数外**，否则算**专业课**（依据=标注，最准）；
2. 没有 `subj` 但勾了「允许拿题干猜」→ 拿题干里的关键词猜（依据=猜）；
3. 都判不出来 → **未分类**。

两个关键词框都能改（逗号/顿号/空格分隔），改完点「预览」会告诉你：会分成几份、每份多少条、
其中多少条是猜出来的、多少条年级未知。输出目录默认在桌面的 `题库归并-时间戳`；
勾上「同时输出 .js 包装文件」还会给每份配一个 `.js`：

```js
// 由「易智教 · 题库编辑器」导出 —— 25级-语数外（128 条，2026-10-11 14:03）
const bank = { ... };
if (typeof module !== 'undefined' && module.exports) module.exports = bank;
if (typeof window !== 'undefined') window.__YZJ_BANK__ = bank;
```

也就是 **Node 里 `require('./25级-语数外.js')`、网页里 `<script src>` 都能直接吃到这份题库**；
`.json` 那份就是给「易智教助手」的「导入题库」用的。

⚠️ 老数据（v1.4.7 之前采集的，没有 `cls`/`subj`）**分不干净**，会整堆进「年级未知-未分类」。
这不是 bug，是那些条目里确实没写来源。实测桌面那份 `yzj-bank-2026-10-08.json`（383 条，v1.4.6）
就是 383/383 全进未分类。**v1.4.7 之后新采集的库才能精确分。**

### 命令行版（写进脚本 / 定时任务用）

```powershell
# 看会分成什么，不写文件
python quiz\bank_editor\bank_split_cli.py "D:\导出\" --dry-run

# 真出文件，.json + .js 都要
python quiz\bank_editor\bank_split_cli.py "D:\导出\" -o "D:\题库" --js --min 2

# 单个库
python quiz\bank_editor\bank_split_cli.py "C:\...\yzj-bank.json" -o "D:\题库"
```

其它开关：`--no-guess`（不许猜）、`--public "语文,数学"` / `--major "电动机,PLC"`（换关键词）、
`--policy new|old|skip`（撞 key 怎么办）、`--min N`（少于 N 条的组不出文件）、`--quiet`。

### AI 整理（v2.4，极简 Agent）

工具栏的 **「AI 整理…」** 不是让模型自由发挥，而是一个被收得很紧的 Agent：

```
扫描题库 → 分批问模型 → 程序校验 → 你勾选 → 才落库（可 Ctrl+Z）
```

它只做三件**只看题干就能判**的事：

| 任务 | 说明 | 用途 |
|---|---|---|
| **补科目 subj** | 从题干判断这是哪门课，写进 `subj` | 老题库没有课程名，补上之后「按年级 × 科目分流」才分得动 |
| **标无效题** | 老师布置的开放作业/拍照上传之类 | 建议从题库删掉，免得占 key、被误命中 |
| **找近似重复** | 同一道题的两种表述 | 只删信息少的那条，不会两条都删 |

**故意不做「补答案」**：题库只存题干前 100 字、**不存选项**，凭题干补答案很容易把错答案写进库。

几个安全设计：

- **先预览**：AI 的每条建议都会列成表（原值 / 新值 / 理由 / 置信度），默认全选，但只有点「应用选中」才动数据；
- **程序校验**：不存在的 key、超长/带标点的"科目"、模型瞎编的重复关系，全部丢掉；
- **可撤销**：整个整理算一步，`Ctrl+Z` 能整批回滚；删除前还会再确认一次；
- **不写文件**：应用后只是标脏，点「保存」才落盘（保存前照例自动 `.bak`）；
- **只处理有题干的条目**：`i… / d… / p…` 图片键没有文字，直接跳过；
- **省 token**：默认最多 200 条、每批 20 条，可自己调。失败的那一批只记错误，不影响别的批。

AI 配置：默认直接复用根目录 `config.json` 里的 `ai` 段（provider / base_url / model / api_key），
在对话框里改过之后存到 `quiz\bank_editor\ai_config.json`（本地明文，权限尽量收紧）。
内置 DeepSeek / OpenAI / Claude / Gemini / Kimi / 智谱 / 通义 / 硅基流动 / OpenRouter / 本机 Ollama / 自定义，
「检测模型」跟油猴脚本里那个是同一套思路（`GET {base}/models`）。

实测（DeepSeek，4 条真题）：4 条全部补出科目（光伏电池制造技术 ×3、计算机网络 ×1），
置信度 0.9–0.95，零错误。

## 题库文件长什么样（看这里才不会搞混）

```json
{
  "__meta__": { "count": 224, "exportedAt": 1791216602971, "latestAt": 1791207472410 },
  "q1a2b3c":  { "a": "ABD", "q": "交换机接口模式有哪些？", "t": 1, "at": 1790..., "src": "learn" },
  "i5a5e7776@3": { "a": "C", "at": 1790..., "src": "official" },
  "p10bo642": { "a": "1C#2A", "at": 1790..., "src": "official" }
}
```

| key 前缀 | 含义 | 有没有题干 |
|---|---|---|
| `q…` | 按**题干+选项**算的指纹（跨班级跨账号都能命中） | 有（v1.4.4 起才写 `q`） |
| `i…` | 按**试卷图片**的 SHA 算的指纹 + 题号 | 没有 |
| `d…` | 按**试卷图片**的感知哈希 + 题号（抗重压缩） | 没有 |
| `p…` | 按**卷子(tmid)+题号**算的指纹 | 没有 |

### 来源标注（v1.4.7 起）

每条题现在还会带上三个字段，写入题库时就一起记好：

| 字段 | 是什么 | 从哪来 |
|---|---|---|
| `subj` | **科目 / 课程名** | 任务列表接口的 `tc_name`（如「光伏电池制造技术」） |
| `cls` | **班级名** | 同一个接口的 `tt_name`（如「25级05班」） |
| `stu` | **学号** | `sessionStorage.login_number`（如 `2024130038`） |
| `who` | 姓名（方便人看） | `sessionStorage.login_name` |

- 只有带题干的 `q…` 键才写题干；**`i…`/`d…`/`p…` 图片版键也带来源标注**（只是没题干）。
- v1.4.7 之前入库的老条目没有这几个字段，编辑器里显示 `-`，用科目筛选选「（没标科目）」能一次性挑出来。
- 搜索框现在也能搜科目和学号：输入「光伏」或「2024130038」都能命中。

⚠️ **老条目（v1.4.7 之前）里没有任何来源信息**。所以：

- v1.4.7 之后采集的 → 有 `cls`/`subj`，按**年级 × 科目**分得很准（见上面那节）；
- 老条目 → 只能拿题干猜科目，年级基本猜不出来（题干里很少有「25级」）；
- 只有哈希的（`i…`/`d…`/`p…`）→ 连题干都没有，只能按「整卷图片」把同一套卷子的题聚在一起；
  要有班级归属，得拿该班的**任务列表（tmid）**回来反推 `p…` 键（`p` 键就是 `hash32(tmid + "#" + 题号)`，
  算法在油猴脚本里）。
